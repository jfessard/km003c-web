PDM session · serial

Get contract opens a pdm session, which takes over the dongle's PD engine (charging blips while it reads). Left open, the session keeps owning the engine: the charger parks at 5V, downstream negotiation flaps, and bulk PD reads come back REJECT. Auto-exit sends pdm close when the read finishes so everything re-negotiates cleanly. Uncheck only to keep the session for manual pd … commands — then press Exit PDM (above) when done.
