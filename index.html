Manual serial commands

Connect serial to send commands. Keep PDM open for manual PD requests, then exit when done.

Session: pdm open · pdm close · pdm set type=?,em=? (type 0 auto, 1 PD3.0, 2 PD3.1, 3 priv-PPS; em 0 off, 1 20V5A, 2 50V5A EPR)
PD: entry pd then pd pdo (Source_Cap) · pd req=?,cur=? (req = PDO#, e.g. pd req=2,cur=20000) · pd req=?,volt=?,cur=? (PPS/AVS, e.g. pd req=5,volt=12000,cur=20000) · pd cmd=? · pd data=? (1st byte SOP, next 2 header, no CRC)
QC: qc 9V · qc3 volt=5000 (3600–20000mV) · qc3 inc=8 / qc3 dec=6   Others: entry qc|fcp|scp|afc|vfcp|sfcp|ufcs then fcp 9V · scp volt=?,cur=? · vfcp volt=?,cur=? · ufcs pdo · reset
Units are mV/mA. An open PDM session owns the PD engine (charger parks at 5V) — Exit PDM when done. help/reboot get no reply on this firmware. Full syntax: official virtual-serial trigger doc (PDF).
